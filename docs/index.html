How it works
PoolWETH/USDC on Base Sepolia emits Swap events
→
ReactiveOn Lasna, watches the pool, tracks price and EMA, and requests a buy when one is due
→
VaultOn Base Sepolia, swaps 1 USDC for WETH directly against the pool

The guard is deterministic: if the spot price drops more than the trip percentage below the reference price, the reactive pauses the vault; when the EMA recovers above the resume level, buying continues. The reference updates only on confirmed fills, so a crash cannot drag the baseline down with it.

To resume after a debt stall, the owner tops up the reactive, repays the debt with coverDebt(), and sets a new interval with setRule(). Nothing on this page sends a transaction — it only reads.
